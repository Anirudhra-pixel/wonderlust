# Wanderlust - Travel Website

Wanderlust is a simple travel website made for a frontend assignment. It shows a few travel destinations with images, short descriptions and sample starting prices.

## Features
- Navigation links to the main sections
- Hero section with a call-to-action button
- Destination cards with images and descriptions
- About section
- Footer navigation
- Responsive navigation for smaller screens

## Technologies Used
- HTML
- CSS
- JavaScript

## Run Locally
1. Download or clone this repository.
2. Open the `Wanderlust` folder in Visual Studio Code.
3. Open `index.html` with the Live Server extension.

## Project Structure
- `index.html` - page content
- `css/` - stylesheets
- `js/` - navigation behaviour
- `assets/` - images and icons
- `design/` - supplied Figma reference images

## Note
This is a student frontend project. The destination names, descriptions and prices are sample website content, not live travel offers. The page does not process bookings or store visitor information.
